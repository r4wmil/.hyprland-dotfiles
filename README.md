# Me dotfiles for Hyperland

## Setup
```
stow src
# - create symlinks
stow -D src
# - delete symlinks
```

## Dependencies (Archlinux)
```
sudo pacman -S \
    hyprland hyprshot hyprpicker \
    foot ttf-fira-code \
    wl-clip-persist fuzzel \
    nemo viewnoir
```
